# 组件与模块说明

## 组件树

```text
App
├── Routes
│   └── Home
│       ├── TopBar
│       ├── SidePanel
│       │   └── SidePanelContent
│       ├── ChatArea
│       │   └── MessageItem
│       │       └── SourceCard
│       ├── Sheet（移动端导航）
│       │   └── SidePanelContent
│       ├── MistakesPanel
│       └── Toaster
```

## 页面与组件职责

### `App`

挂载路由和全局通知，订阅主题变化并同步给通知组件。

### `Home`

页面的状态协调中心，负责：

- 并发加载元数据、统计和健康状态；
- 按 `kbId` 恢复、保存、切换和删除会话；
- 维护当前模式、主题、Top-K、输入与消息；
- 管理请求所有权、停止、错误重试与流式阶段；
- 在面试回答完成后提取并自动收录错题；
- 向桌面侧栏与移动抽屉提供同一份状态和回调。

### `TopBar`

展示应用名、模型与知识库统计、健康状态；提供 Top-K 设置、主题切换和移动端菜单入口。应用名来自 `meta.appName`，不在组件内硬编码知识库品牌。

### `SidePanel` / `SidePanelContent`

桌面侧栏是响应式容器，`SidePanelContent` 是可复用的纯展示内容，包含模式切换、新对话、错题本、历史会话与主题导航。`modes` 不含 `interview` 时隐藏面试相关入口。

### `ChatArea`

负责消息列表、空态引导、自动滚动与输入区：

- 空态品牌、示例和面试引导由 `meta` 驱动；
- 仅用户停留在底部时跟随流式消息滚动，向上阅读时不强制拉回；
- Enter 发送、Shift+Enter 换行，兼容中文输入法组合状态；
- 流式期间可停止，输入框仍可预输入下一条内容。

### `MessageItem`

渲染用户与助手消息、Markdown、流式光标、阶段提示、错误重试、来源和复制 / 收藏操作。`kbId` 用于隔离错题存储，`canSaveMistake` 控制面试领域功能是否出现。

### `SourceCard`

展示单条检索资料、出处与相关度。相关度阈值集中在 `src/lib/constants.ts`。

### `MistakesPanel`

提供错题查看、主题筛选、排序、答案展开、已掌握、还不熟和再考一次。删除和复习操作通过 `kbId` 写入对应命名空间。

## 关键模块

| 模块 | 职责 |
| --- | --- |
| `lib/api.ts` | 四个 HTTP 端点与响应格式校验 |
| `lib/sse.mjs` | 跨 chunk 帧解析、CRLF 归一化、多行 data、done 幂等处理 |
| `lib/sessions.ts` | 会话存取、容量限制、标题、活动会话和重试问题定位 |
| `lib/mistakes.ts` | 错题去重、筛选、排序、复习与题目 / 答案提取 |
| `lib/citations.ts` | 引用标记转锚点、定位和高亮 |
| `lib/theme.ts` | 主题加载、应用、持久化与变化事件 |
| `types/index.ts` | API、消息、会话、错题和 SSE 的共享类型 |

## 数据流原则

1. **元数据决定能力，而非领域硬编码**：新后端通过 `meta` 提供品牌、模式和示例即可复用界面。
2. **展示组件不拥有请求生命周期**：请求与持久化集中在 `Home`，便于处理竞态和跨组件状态。
3. **存储按知识库隔离**：所有会话与错题读写必须显式传递当前 `kbId`。
4. **稳定终态才落盘**：流式中间态不写入会话，避免刷新后恢复到半截回答。
5. **纯逻辑与视图分离**：SSE、引用、会话、错题和主题逻辑均可独立测试。
